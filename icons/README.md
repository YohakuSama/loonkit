# LoonKit 图标

正式版的 33 个策略组图标及网络诊断图标保存在 [v20261021r1](./v20261021r1/)。对应可编辑 SVG 源文件位于 [source](./source/)。

## 新策略图标

[v20261025r1](./v20261025r1/) 新增 6 个待启用的应用策略图标：GitHub、ChatGPT、Gemini、Claude、Speedtest、Cloudflare。

素材均通过 Apple App Store 官方应用 ID 和发布者核对。所有输出均为 **512 × 512 RGBA PNG**，采用与正式版一致的圆角处理。GitHub、ChatGPT、Gemini 对外缘玻璃质感进行裁切，其他图标不做无意义的放大。

素材来源、App Store 页面、原始图像地址和 SHA256 记录在 [sources.json](./v20261025r1/sources.json)，生成脚本为 [build_appstore_icons.py](../scripts/build_appstore_icons.py)。应用名称与标志的权利属于相应权利人；项目使用图标标识对应应用策略，不代表平台认可或赞助。
