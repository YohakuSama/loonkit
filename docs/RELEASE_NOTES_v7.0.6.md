# LoonKit v7.0.6

网络辅助插件更新；正式规则集及原有分流完全不变。

- 移除插件内的网络切换自动提醒和开关；三个手动工具保留。
- 节点信息以出口、地区、ASN、网络特征和可选直连对照为主要内容。
- 网络检测分别使用可直连的 204 地址和 HTTPS 节点探测；DNS 状态单独展示，不再把直连或 DNS 失败判定成节点连接失败。
- 解锁检测仅针对所选节点，移除 Discovery+ 的账号接口请求；YouTube Premium 只检查节点访问和地区响应，不判断账户权益。
- 解锁结果改为「区域可用」「地区受限」「接口可访问」「片源页面可访问」「待确认」「检测失败」，不再夸大 Netflix 404 或网页返回的含义。

保留原有 43 个完整版远程规则与 196,561 条匹配条件。网络辅助入口固定到新插件和新脚本 Git 提交。未宣称已完成真机测试。
