# LoonKit · 实机界面与操作说明

本指南依据 2026-10-26 核对的 Loon App 界面整理。按钮位置和措辞可能随 App 版本变化，请以实际安装版本为准。

## 配置文件

**首次导入实际路径：** 配置 → 所有配置文件 → 右上角 ＋ → 从链接导入。

链接导入面板包含 `URL` 和 `托管`。开启「托管」后才会显示「更新频率」和「全覆盖更新」。首次完整部署可开启全覆盖，前提是已经备份；**日常更新时建议关闭全覆盖**。

**长按配置文件的实际菜单**：应用、编辑、重命名、启用 iCloud、导出、删除。已核对的长按菜单中没有「更新策略」；如需调整托管选项，请以当前配置管理界面为准。

## DNS

默认使用 **AliDNS**，主要在中国大陆网络使用时可直接保留。也可自行选择可信的自建解析器，或在中国大陆提供稳定接入且按需支持 ECS 的 DNS（应核对服务商说明）。

在 **配置 / 设置 → DNS → DNS 服务器** 页面核对以下两项：

1. **DoH 服务器与流量模式**：如果换成**需要代理访问的海外 DoH**，先替换 AliDNS 的完整 HTTPS URL，再把「DoH 流量模式」从 `DIRECT` 改为 **`RULE`**；检查解析器域名/IP 的规则是否实际命中可用代理。国内解析器直连可用时通常保留 `DIRECT` 即可。`RULE` 不是解析成功的保证。
2. **查询回落**：隐私优先时可**关闭**，避免 Loon 在加密 DNS 失败后回落普通 DNS；如果所选 DoH 不可达，可能解析失败。它与「DoH 流量模式」无关，也不能代替对其他应用和节点 DNS 路径的检查。

如果托管配置发生全覆盖更新，请再次确认 DoH 服务器、流量模式和回落开关是否仍符合预期。详见 [DNS 设置与连通性检查](./DNS_PRIVACY.md)。

## 插件功能

从策略页选择**单个节点**，在节点菜单中运行「节点信息」「网络检测」「解锁检测」。这是手动操作，不需要自动扫遍所有节点。

- 节点信息：区分入口、实际出口 IP、运营商/ASN 与第三方网络标签；「未检出」不代表家宽证明。
- 网络检测：区分节点请求、DIRECT 连通性与 Loon DNS API 的解析结果。
- 解锁检测：依据所选节点的服务接口响应提供辅助判断，不代表会员权益或永久可用。

当前诊断工具针对较慢的初次连接保留了更充分的请求时间：瞬时错误会在相同节点有限重试，插件仍会报告真正的失败或未知状态。更多信息见 [网络诊断](./NETWORK_DIAGNOSTICS.md)。
