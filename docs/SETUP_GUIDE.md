# LoonKit · 实机界面与操作说明

本页根据用户提供的真实 Loon App 截图（2026-10-26）核对；不采用 AI 生成的 App 界面作为教程。界面文案随 Loon 版本调整，请以安装版本为准。

## 配置文件

**首次导入实际路径：** 配置 → 所有配置文件 → 右上角 ＋ → 从链接导入。

链接导入面板包含 `URL` 和 `托管`。开启「托管」后才会显示「更新频率」和「全覆盖更新」。首次完整部署可开启全覆盖，前提是已经备份；**日常更新时建议关闭全覆盖**。

**长按配置文件的实际菜单**：应用、编辑、重命名、启用 iCloud、导出、删除。图中没有「更新策略」，不要误导用户在长按菜单中寻找不存在的项目。

## DNS

**配置 / 设置 → DNS → DNS 服务器 → 查询回落 → 关闭**。这是 Loon App 的开关，不可假定导入配置就自动替用户关闭。界面还显示「包含系统 DNS 地址」「DoH 流量模式 DIRECT」和独立的 AliDNS DoH 条目，它们与查询回落不是同一个参数。

关闭回落可防止某些加密 DNS 失败后的普通 DNS 重试，同时降低失败时的可用性；**不能独立证明全设备无 DNS 泄漏**。

## 插件功能

从策略页选择**单个节点**，在节点菜单中运行「节点信息」「网络检测」「解锁检测」。这是手动操作，不需要自动扫遍所有节点。

- 节点信息：区分入口、实际出口 IP、运营商/ASN 与第三方网络标签；「未检出」不代表家宽证明。
- 网络检测：区分节点请求、DIRECT 连通性与 Loon DNS API 的解析结果。
- 解锁检测：报告七项服务接口的访问情况，不能当作会员权益或永久可用保证。

v7.0.9 优化了高延迟节点首次探测的时间预算：瞬时错误会在相同节点有限重试，插件仍会报告真正的失败或未知状态。更多信息见 [网络诊断](./NETWORK_DIAGNOSTICS.md)。
