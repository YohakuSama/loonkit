# LoonKit v7.0.7

节点信息和服务检测显示优化。43 份规则、196,561 条匹配条件及分流配置保持不变。

- 节点信息优先使用节点菜单选中的节点，使用 ipquery.io 与 ipwho.is 两源查询出口 IP。IP 不同则分别列出；地区、ASN 或运营商不同则明确标识「不一致」。
- 一个来源失效时标记「单源」，移除未被可靠核验的风险评分、机房分类；可选直连出口对照保持默认关闭。
- 解锁检测提供醒目的 ✅、⛔、⚠️ 状态与精简可访问数量汇总，仍仅检测所选节点的七个平台接口，不读取账号信息或会员权益。
- 网络检测、无自动切换提醒的结构、规则、DNS、TUN 和 Beta 均未改动。

新版脚本、插件均固定为不可变 Git 提交。保留正式版 v7.0.6 回滚入口；尚未进行真实 Loon 设备验证。
