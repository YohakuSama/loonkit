# Loon App 设置

| 设置 | 建议值 |
| --- | --- |
| 工作模式 | 规则分流 |
| DNS 明文回退 | 关闭「加密 DNS 失败回退到普通 DNS」 |
| 远程规则与插件 | 启用，导入后刷新 |
| 脚本 | 使用网络辅助时开启 |
| Wi-Fi 共享 | 按需开启，默认关闭 |
| MitM | 仅在另行安装的插件确有需要时启用 |

配置不包含节点。添加节点后，在 Proxy 和各服务策略组中选择线路。Apple、Microsoft、Paypal、Bilibili 的国内线路由地区规则处理，服务策略组选择代理线路。
