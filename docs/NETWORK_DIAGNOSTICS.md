# 网络辅助

[插件文件](../release/Network_Diagnostics.plugin) · [返回首页](../README.md)

## 节点信息

通过两个来源核对所选节点的出口 IP、地区、运营商和 ASN；数据不同则标为待核实。可选直连出口对照。

## 网络检测

手动检测所选节点的 HTTPS 连通性、直连网络，以及当前 Loon DNS 解析。直连使用可在国内访问的 204 检测地址。DNS 查询需 Loon Build 988+。

## 节点解锁检测

仅通过所选节点测试 DAZN、Discovery+、Paramount+、Disney+、Netflix、ChatGPT、YouTube Premium 的服务接口、访问限制或区域响应。不访问账号资料接口，也不判断会员权益。结果使用醒目的状态符号逐行显示。

## 更新

更新主配置后，在 Loon 中刷新插件及远程脚本。
