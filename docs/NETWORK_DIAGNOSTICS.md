# 网络辅助：检测入口与结果解读

网络辅助插件提供节点信息、连接检测及服务访问检测。结果用于辅助定位问题，不能替代 Loon 请求记录或抓包；节点筛选和 DNS 服务器设置分别有独立说明。

## 从哪里运行

在 Loon 策略页选定**单个节点**，进入节点菜单，按需运行「节点信息」「网络检测」或「解锁检测」。如果界面中未出现这些入口，检查当前配置是否启用 [网络辅助插件](../release/Network_Diagnostics.plugin)，以及远程插件/脚本是否已刷新。

插件的 `target_policy` 可以指定目标策略；优先通过节点菜单明确选中实际节点。对照直连 IP 的选项 `compare_direct` 默认关闭，不会自行切到其他节点替用户检测。

## 三项检测的区别

| 功能 | 数据或检测对象 | 不能得出的结论 |
| --- | --- | --- |
| **节点信息** | 通过 `ipconfig.is` 获取出口 IP、地理标签、ASN/运营商等；可将 Loon 提供的节点入口协议等信息分开显示 | 第三方「机房 / 家宽 / VPN」标签不等于物理位置或 IP 类型的最终证明。 |
| **网络检测** | 检查选定节点的 HTTPS 连通性、独立的直连联网探测，以及 Loon DNS API 的解析结果；直连使用独立 204 目标 | DNS 成功并不证明全部 App 都经同一解析通道；原生 DNS 查询需 Loon Build **988+**。 |
| **解锁检测** | 仅从所选节点访问 DAZN、Discovery+、Paramount+、Disney+、Netflix、ChatGPT、YouTube Premium 相关服务接口并解释区域/权限响应 | 不查询个人会员资料，不代表拥有付费权益，也不能保证平台后续一直可访问。 |

## 结果异常怎么判断

| 看到的现象 | 下一步 |
| --- | --- |
| 节点信息有出口 IP，但目标服务仍失败 | 分开检查**出口识别**和**服务自身响应**；前者不能代替解锁或服务访问测试。 |
| 网络检测中节点失败、直连正常 | 优先核对当前选中的节点、协议、握手及请求记录，不用直连成功推断代理可用。 |
| 仅 DNS 查询失败 | 查看[DNS 服务器与查询回落](./DNS_PRIVACY.md)，并核对 Loon Build 和请求日志；不要从一次 DNS API 调用判断全设备路径。 |
| 解锁检测返回限制、未知或超时 | 在同一节点复测并检查平台请求记录；响应状态不等于订阅权益状态。 |

## 超时与重试边界

对短暂连接错误，当前诊断会在**原选中节点**上最多重试一次，持续失败仍应显示失败或未知；不会自动改用 `DIRECT` 或另一节点制造成功结果。解锁检测限制并发，较慢网络下整轮可能接近 **69 秒**。持续异常应记录节点、时间、网络环境、目标服务与脱敏后的请求/脚本日志，避免提交密钥或私人订阅。
