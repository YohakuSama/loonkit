# 网络辅助

[正式版诊断插件 v7.0.9](../release/v7.0.9/Network_Diagnostics.plugin) · [返回首页](../README.md)

## 节点信息

使用单一数据源 `ipconfig.is` 查询实际出口 IP、国家、地区、城市、ASN、运营商、IP 网段、反向 DNS、时区、估算坐标，以及机房、移动网络、VPN、Tor 识别结果。Loon 提供节点协议、入口信息时分开显示。第三方识别标签不等于物理位置或「家宽」证明。可选直连出口对照默认关闭。

## 网络检测

手动检测所选节点的 HTTPS 连通性、直连网络，以及当前 Loon DNS 解析。直连使用可在国内访问的 204 检测地址。DNS 查询需 Loon Build 988+。

## 节点解锁检测

仅通过所选节点测试 DAZN、Discovery+、Paramount+、Disney+、Netflix、ChatGPT、YouTube Premium 的服务接口、访问限制或区域响应。不访问账号资料接口，也不判断会员权益。结果使用醒目的状态符号逐行显示。

## 更新

更新主配置后，在 Loon 中刷新插件及远程脚本。请确保正在使用 v7.0.9 的版本化插件；网络与解锁探测针对短时错误在**相同节点**最多重试一次，持续失败不会假报成功。

## 慢速节点检测（v7.0.9）

检测现在会在所选节点上对短时连接故障最多重试一次，不会自动切换 DIRECT 或别的节点。解锁检测控制并发数量，最慢可能耗时接近 69 秒；仍然不能凭单次接口失败断言节点永久不可用。请在 iOS 真机对曾误报的节点复测。
